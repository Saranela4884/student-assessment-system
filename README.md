# Student Assessment System

A Streamlit web application for student assessment and automatic ranking.

## Features
- Student name
- Tema /20
- Design /30
- Kreativiti /30
- Originality /20
- Automatic total /100
- Status
- Kira Semua Markah
- Automatic ranking
- Top 3 winners 🥇🥈🥉
- Delete student
- CSV download

## Run locally

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Deploy

1. Upload `streamlit_app.py` and `requirements.txt` to a GitHub repository.
2. Sign in to Streamlit Community Cloud.
3. Create a new app.
4. Select the GitHub repository.
5. Set the entrypoint to `streamlit_app.py`.
6. Deploy.
